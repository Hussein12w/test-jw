# ثيم JW Store — دليل التركيب

ثيم ووكومرس مخصص لمتجر jwstore.ae. يدعم العربية (RTL) والإنجليزية (LTR)، وهو مصمم للجوال أولاً (منتجان في كل صف). فيه سلة جانبية، ومفضلة، وزر "اشترِ الآن"، وأقسام تلقائية في الصفحة الرئيسية.

## قبل التركيب (مهم)
1. خذ **نسخة احتياطية كاملة** للملفات وقاعدة البيانات، مثلاً عبر UpdraftPlus أو من لوحة الاستضافة.
2. الأفضل أن تجرّب الثيم أولاً على **نسخة Staging** إذا كانت الاستضافة توفرها.
3. تغيير الثيم **لا يحذف** المنتجات أو الطلبات أو العملاء أو الإعدادات، لأنها كلها محفوظة في قاعدة البيانات.

## التركيب
1. اذهب إلى: المظهر ← قوالب ← إضافة جديد ← رفع قالب، واختر ملف `jwstore-wordpress-theme.zip`.
2. اضغط **معاينة مباشرة** أولاً لترى الشكل، ثم **تفعيل**.
3. عند التفعيل تُنشأ صفحة **المفضلة** (Wishlist) تلقائياً.

## الأشياء التي تبقى تعمل كما هي
- **Code Snippets** بكل ما فيه: رمز الدرهم، ورسوم الدفع، وإخفاء الدفع عند الاستلام وتمارا خارج الإمارات، وتحديد Stripe افتراضياً، وشحن الخليج بالوزن. الثيم لا يغيّر صفحة الدفع، فهي صفحة ووكومرس القياسية.
- إضافات الدفع: Stripe وTabby وTamara والدفع عند الاستلام.
- **TranslatePress غير مطلوبة:** الثيم يترجم بنفسه (انظر قسم الترجمة). إذا فعّلتها لاحقاً يستخدمها زر اللغة تلقائياً.

> ملاحظة: إذا كانت صفحة الدفع (Checkout) مبنية بـ"بلوكات" ووكومرس الجديدة، فقد لا يعمل كود jQuery الخاص بإخفاء الكوبون. لتحويلها إلى الصفحة الكلاسيكية: افتح صفحة Checkout، واحذف البلوك، وضع مكانه `[woocommerce_checkout]`. افعل الشيء نفسه مع صفحة السلة باستخدام `[woocommerce_cart]`.

## الإعدادات (المظهر ← تخصيص ← JW Store)
- **الهيدر:**
  - نص الشريط العلوي بالعربي والإنجليزي، ورسالة تنبيه، مثل مواعيد مركز التركيب في العين.
  - رقم الواتساب، والهاتف، والإيميل، والعنوان، ورابط تتبع الطلب.
  - خانة Shortcode في الشريط العلوي، مثلاً لمحوّل العملات إذا كنت تستخدم إضافة عملات.
- **السلايدر:** 3 شرائح، لكل واحدة صورة (المقاس المقترح 1600×600) وعنوان ونص بالعربي والإنجليزي ورابط. الشريحة التي ليس لها صورة تُظهر رسمة سيارة جيمني الموجودة في الثيم، وللأفضل ارفع صورة حقيقية لسيارة جيمني من متجرك.
- **الصفحة الرئيسية:**
  - ترتيب الرئيسية: الأقسام ← منتجات جيمني ← وصل حديثاً ← باقي الفئات ← العروض ← كيف نعمل.
  - «القسم الأول» يجمع كل الفئات التي في اسمها كلمة `jimny`، ويمكنك تغيير الكلمة والعنوان.
  - تفعيل أو إخفاء أي قسم: المميزة (مخفي افتراضياً)، والعروض، والجديد، والأكثر مبيعاً، وكيف نعمل.
  - الأقسام التي تظهر في الرئيسية، تكتب slugs مفصولة بفاصلة، مثلاً: `jimny-3-doors,jimny-5-doors,jetour,defender`.
  - عدد المنتجات في كل قسم، وبانر العروض.
- **المتجر:**
  - إخفاء المنتجات النافدة من الرئيسية.
  - عدد المنتجات في الصفحة، والسلة الجانبية، وزر "اشترِ الآن".
  - حد الشحن المجاني (يظهر شريط تقدّم في السلة، وقيمة 0 تخفيه)، وبانر جانبي.
- **السوشيال ميديا:** روابط Instagram وTikTok وSnapchat وYouTube وFacebook.
- **الشعار:** المظهر ← تخصيص ← هوية الموقع. شعار JW مضاف مسبقاً داخل الثيم.

## القوائم (المظهر ← القوائم)
- **Main menu:** القائمة تحت الهيدر. إذا تركتها فارغة تظهر تلقائياً: الرئيسية، والمتجر، والأقسام، والعروض.
- **Top bar links:** روابط الشريط العلوي.
- **Footer — Shop** و**Footer — Help & policies:** أعمدة الفوتر.
- لا تضف رابط "Arabic" في القائمة، لأن زر اللغة موجود في الهيدر.

## الأقسام والمنتجات
- كل منتج جديد يظهر تلقائياً في "وصل حديثاً" وفي قسمه.
- كل قسم جديد يظهر تلقائياً في "تسوق حسب القسم" و"جميع الأقسام".
- صورة القسم تُضاف من: منتجات ← التصنيفات ← تعديل ← الصورة المصغرة.
- ترتيب الأقسام يتم بالسحب في صفحة التصنيفات.
- المنتجات "المميزة" هي التي عليها نجمة ⭐ في قائمة المنتجات.
- "العروض" تعرض المنتجات التي لها سعر تخفيض.

## الترجمة (بدون TranslatePress)
الثيم يترجم الموقع بنفسه. زر اللغة في الهيدر يغيّر اللغة واتجاه الصفحة (RTL / LTR)، ويحفظ اختيار الزائر.

**1. نصوص ووردبريس وووكومرس** (أضف إلى السلة، إتمام الطلب، حقول الدفع…):
- تُترجم تلقائياً من ملفات العربية الرسمية.
- للتأكد أنها منزّلة: لوحة التحكم ← التحديثات ← **تحديث الترجمات**.
- إذا لم تكن منزّلة: الإعدادات ← عام ← لغة الموقع ← العربية ← حفظ، ثم حدّث الترجمات. بعد ذلك يمكنك إرجاع لغة لوحة التحكم الخاصة بك للإنجليزية من: المستخدمون ← ملفك الشخصي ← اللغة.
- اللغة التي يراها الزائر أول مرة: تخصيص ← JW Store ← الهيدر ← اللغة الافتراضية.

**2. أسماء المنتجات ووصفها:**
- في صفحة تعديل أي منتج يوجد صندوق **«الترجمة / Translation»** فيه: العنوان، والوصف المختصر، والوصف الكامل، بالعربي والإنجليزي.
- اترك الحقل فارغاً ليظهر النص الأصلي.
- نفس الصندوق موجود في الصفحات (مثل الشروط والخصوصية).

**3. الأقسام (التصنيفات):**
- منتجات ← التصنيفات ← تعديل.
- الحقول هي: **الاسم بالعربي** و**Name in English**، والوصف لكل لغة.

**4. القائمة:**
- اكتب اسم الرابط بهذا الشكل: `الرئيسية | Home`. كل لغة تأخذ نصفها.
- روابط الأقسام في القائمة تأخذ الاسم المترجم تلقائياً.
- نفس الطريقة تعمل لاسم الموقع: `جي دبليو ستور | JW Store`.

**5. نصوص الثيم:** مترجمة في الملفين `languages/ar.po` و`ar.mo`. نصوص التخصيص (الشريط العلوي، السلايدر، العروض…) لكل واحد منها خانة عربي وخانة إنجليزي.

**الكاش:** الثيم يطلب من LiteSpeed Cache أن يحفظ نسخة لكل لغة، فلا يرى زائر الإنجليزي صفحة عربية من الكاش. بعد التحديث اضغط Purge All مرة واحدة.

> لترجمة أسماء منتجات كثيرة دفعة واحدة: ووكومرس ← المنتجات ← تصدير (CSV). أضف عموداً باسم `Meta: _jw_title_en` واكتب فيه الأسماء الإنجليزية، ثم استورد الملف مع خيار «تحديث المنتجات الموجودة».

## إذا لم يظهر شيء كما يجب
- امسح الكاش: إضافة الكاش، وCloudflare، وكاش الاستضافة.
- الإعدادات ← الروابط الدائمة ← حفظ، بدون تغيير أي شيء.
- ووكومرس ← الإعدادات ← الموقع: تأكد أن **Site visibility** على **Live**.
